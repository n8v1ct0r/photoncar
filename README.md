# Photoncar

Live demo: https://photoncar.vercel.app

Read-only edge telemetry for cars. It fuses CAN, OBD-II, GPS, and IMU data into 1 timeline, and every alert cites the signals that triggered it.

Not a safety system. Do not use while driving.

Status: live demo. It replays a recorded public drive (comma2k19); throttle and coolant are simulated. The in-car device is still in development.
